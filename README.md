# AI_storage_daily_push_system
工作流：
- 1、给出一个参考链接，先跟一个AI交谈得到可能的坑，再与实操者交谈验证坑
- 2、与CC对话生成设计文档
提示词：
```
https://www.pushplus.plus/shortMessage/e56da0841764486e84441e45d917ed50 查看并和我讨论如何用AI编程实现类似的界面+主题+消息抓取+发送，先别写代码。关于数据源，并不固定，只搜 24-48 小时发布的消息，每天会和昨天的热点内容做去重。采用英文数据源减少引用转发产生的旧闻，对关键热点做持续报道。分成几个agent，要尽量避免人在环路的操作，跑通后可复用，只做改进。
```
- 3、与DS对话按照设计文档生成代码
提示词：
```
这是初始需求：https://www.pushplus.plus/shortMessage/e56da0841764486e84441e45d917ed50 根据这个案例用AI编程实现类似的界面+主题+消息抓取+发送。关于数据源，并不固定，只搜 24-48 小时发布的消息，每天会和昨天的热点内容做去重。采用英文数据源减少引用转发产生的旧闻，对关键热点做持续报道。
根据设计说明书，第一步把通用模板 + 存储主题的配置 + 几条假数据搭出来，直接出一版可视化效果给我看，让我觉得判断布局/风格哪里需要调整
```
