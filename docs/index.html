📋 一段话总结

2026年9月16日，据voi.id报道，三星计划在2026年9月30日与微软合作结束前，将三星画廊的云备份服务从OneDrive切换至谷歌云，用于备份照片和视频。此举是三星与微软合作终止后的替代方案，结果上可能加剧云存储市场的竞争，推动厂商加速生态整合与用户争夺。

背景

三星电子计划将旗下画廊应用（Samsung Gallery）的云备份服务从微软OneDrive迁移至谷歌云，用于存储用户照片和视频。这一迁移发生在三星与微软合作协议于2026年9月30日到期之前，意味着两家公司在该领域的合作即将终止。事件类型为合作变更，关键实体涉及三星、三星画廊、谷歌云、OneDrive和微软。从时间节点看，2026年9月16日前后正是三星密集推进多项业务调整的窗口期：One UI 9.0稳定版于同日开始向Galaxy S26系列推送，基于Android 17；美国ITC于同日对苹果、三星、谷歌启动337音频专利调查；三星与SK海力士拒绝KEPCO的190亿美元电力预付款方案。三星画廊云备份服务的迁移，是三星在软件生态层面重新配置合作伙伴关系的又一动作，反映出其在云服务领域从微软向谷歌倾斜的战略选择。

技术分析

三星画廊应用是三星设备预装的核心影像管理工具，其云备份功能直接关系到用户照片和视频的存储、同步与跨设备访问体验。从OneDrive迁移至谷歌云，涉及数据迁移、API对接、用户账户体系整合以及备份策略的重新设计。技术上，谷歌云在对象存储、全球CDN分发和AI影像处理方面具备成熟能力，三星可借此将画廊备份与谷歌的机器学习服务（如照片分类、搜索、增强）更深度整合。同时，三星One UI 9.0基于Android 17推送，系统层面的云服务框架调整可能与画廊迁移形成协同。迁移的技术难点在于：确保存量用户数据的无缝转移、维持备份可靠性与速度、以及在不同云服务商之间保持隐私合规标准的一致性。此外，三星近期在AI领域动作频繁，包括投资荷兰AI芯片公司Euclyd、发布zHBM内存以提升AI加速器响应速度10倍，画廊云备份迁移至谷歌云后，有望与谷歌的AI基础设施形成更紧密的技术耦合。

市场影响

三星将画廊云备份从OneDrive迁移至谷歌云，对云存储市场格局产生多重影响。首先，这标志着三星与微软在消费级云服务领域长达数年的合作走向终结，微软将失去三星设备带来的大规模用户照片和视频存储流量。其次，谷歌云获得三星这一重量级客户，在消费级云存储市场的份额和影响力将显著提升，尤其是在Android生态内与Google Photos形成协同效应。第三，对三星用户而言，迁移可能带来备份体验的变化，包括存储空间政策、同步速度和跨平台访问方式的调整，用户需要重新适应谷歌云的界面和功能。从更宏观的视角看，这一事件发生在三星在中国市场份额仅剩0.1%的背景下，表明三星正在全球范围内重新评估其软件服务合作伙伴，将资源向更具战略协同效应的平台倾斜。同时，三星与SK海力士在韩国芯片人才争夺、拒绝KEPCO电力预付款方案等事件，共同勾勒出三星在存储与AI基础设施领域持续加码的战略轮廓。

📋 一段话总结

2026年9月17日，华邦电子宣布拟以11.2亿美元收购英飞凌的NOR Flash与F-RAM业务。起因是华邦电子寻求扩大在非易失性存储领域的市场份额，经过双方协商达成收购协议，结果将整合英飞凌相关产品线。此举可能加剧NOR Flash市场的集中度，并影响F-RAM细分领域的竞争态势。

背景

2026年9月16日，华邦电子（Winbond）宣布与英飞凌（Infineon Technologies AG）旗下Infineon Technologies LLC签署股份购买协议，以11.2亿美元（约合75亿元人民币）全现金方式收购英飞凌NOR Flash与F-RAM业务100%股权。该交易以无现金、无债务为基础，已获华邦董事会核准，预计于2027年下半年完成，尚待监管机构审批。交易完成后，目标公司将以“Spansion”（飞索半导体）为名独立运营，总部设于美国硅谷。Spansion品牌诞生于2003年，由AMD与富士通的闪存业务合并而来，2015年被Cypress收购，后随2020年Cypress收购案并入英飞凌。此次收购标志着华邦电子在专用存储器领域的重大战略扩张，同时也是英飞凌剥离非核心资产、聚焦主业的重要举措。

技术分析

本次收购的核心标的为NOR Flash与F-RAM两类非易失性存储技术。NOR Flash以随机读取速度快、可靠性高著称，广泛应用于汽车电子、工业控制及基础设施等对长供货周期和高可靠性有严格要求的场景。F-RAM（铁电随机存取存储器）则具备高速写入、低功耗和高耐久性等特性，在特定工业与汽车应用中具有不可替代性。收购完成后，华邦电子将直接承接英飞凌在该领域的技术积累、客户资源与产品线，其NOR Flash全球市占率预计将逼近40%。值得注意的是，英飞凌在出售后仍保留特种存储器解决方案组合，包括SRAM、HYPERRAM、nvSRAM以及基于SONOS技术的抗辐射存储器产品，显示其剥离的是非核心的NOR/F-RAM业务，而非全部存储产品线。华邦通过独立实体运营并保留硅谷总部，有助于维持业务连续性、稳定原有客户关系并保留核心技术团队。

市场影响

此次交易将显著改变全球NOR Flash市场的竞争格局。华邦电子收购后NOR Flash市占率逼近40%，将进一步巩固其在专用存储器市场的地位，并直接切入汽车、工业及基础设施等高价值终端市场。对英飞凌而言，出售有助于优化资产结构、释放资本，聚焦其核心功率半导体与汽车芯片业务。交易预计2027年下半年完成，期间需获得监管批准，存在一定不确定性。从产业层面看，此次并购可能引发NOR Flash市场集中度提升，中小厂商面临更大竞争压力。同时，Spansion品牌的复活具有象征意义，可能唤起市场对该品牌历史地位的认知，有助于华邦在欧美市场建立品牌信任。此外，全现金交易方式显示华邦具备较强的资金实力和战略决心。

中国国产存储芯片追赶速度惊人：NAND落后1年、DRAM落后2年、HBM落后3年

📰 eu.36kr.com🕒 2026-09-16 10:00
▼
📋 一段话总结

2026年9月，韩国半导体产业协会发布评估报告，指出中国存储芯片厂商与全球领先企业的技术差距正迅速收窄。长江存储在NAND闪存上仅落后约1年，长鑫存储在DRAM和HBM上分别落后约2年和3年，远低于此前约5年的普遍估计。同时，长江存储产能预计2027年初达每月30万片晶圆，2028年增至45万至50万片，并计划在不依赖EUV设备的情况下生产有竞争力的HBM架构。这一进展将加剧全球存储芯片市场竞争，推动行业技术迭代和产能格局重塑。

背景

韩国半导体产业协会（KSIA）最新评估显示，中国存储芯片厂商与全球领先者的技术差距正快速缩小。长江存储（YMTC）在NAND闪存上仅落后约1年，长鑫存储（CXMT）在DRAM上落后约2年，在HBM上落后约3年，而此前普遍估计差距约为5年。这一评估标志着中国存储产业在外部制裁压力下仍实现了显著的技术追赶。与此同时，长江存储正推进上海证券交易所IPO，拟募资49亿美元，其第一季度营收达470.4亿元人民币（约70亿美元），超过2024年全年收入，核心NAND产品收入同比增长近五倍，净利润达333.8亿元，毛利率升至77%。长鑫存储的LPDDR6已进入量产阶段，HBM试产良率约25%。两家厂商正尝试在不依赖EUV光刻设备的情况下生产有竞争力的HBM架构，其中长鑫存储借鉴了长江存储的X-Stacking 3D NAND方案，采用铜-铜混合键合技术替代传统微凸块连接。

技术分析

从技术维度看，中国存储厂商的追赶路径呈现出明显的“非对称创新”特征。长江存储在NAND领域通过X-Stacking架构实现了三维堆叠的差异化突破，该方案不依赖传统微凸块，而是采用铜-铜混合键合技术融合晶圆间铜互连，缩短了堆叠层间的电路路径。这一架构被长鑫存储借鉴至HBM3E的G4工艺堆叠中，形成跨品类技术协同。长鑫存储在DRAM领域落后约2年，HBM落后约3年，但其LPDDR6已实现量产，HBM试产良率接近25%，表明其在先进封装和堆叠控制上取得实质进展。关键突破在于，两家厂商均在未获取EUV光刻设备的条件下推进先进制程，通过架构创新和封装技术弥补光刻精度不足。产能方面，长江存储预计2027年初达到每月30万片晶圆，其中部分用于LPDDR生产；2027年两座新晶圆厂投产后，2028年总产能将增至45万至50万片/月。相比之下，三星NAND产能预计2027年底为每月35万片。这意味着长江存储在产能规模上可能于2028年超越三星。

市场影响

市场层面，长江存储的崛起正在重塑全球NAND竞争格局。Counterpoint Research数据显示，2026年第二季度长江存储以14%的全球NAND出货量份额与铠侠持平，仅次于三星和SK海力士-Solidigm组合，位列全球第三，超越美光。尽管在营收上仍落后于美光和铠侠，且销售更偏向消费级应用而非数据中心，但其出货量排名已具有标志性意义。分析师指出，15%的市场份额是存储制造商为未来增长提供资本开支的最低门槛，长江存储正逼近这一临界点。价格方面，TechInsights数据显示长江存储较日韩美竞争对手具有10%至20%的价格优势，台湾经济研究院研究员Arisa Liu指出中国制造商同规格产品价格优势常超15%，对价格敏感的通用服务器和消费市场极具吸引力。长江存储的IPO募资将用于升级产线和开发下一代存储产品，进一步加速产能扩张和技术迭代。韩国媒体指出，长江存储已跨越三星和SK海力士无法再将其视为低端挑战者的门槛，其意义不仅在于NAND市场份额，更在于使中国存储自给自足以支撑AI芯片和数据中心运行，减少对外国供应链的依赖。
