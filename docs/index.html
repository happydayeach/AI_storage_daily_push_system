NOR闪存供需结构剧变，高容量产品价格或翻倍
💾 闪存🆕 新事件
📰 donews.com🕒 2026-09-14 07:00
▼
📋 一段话总结

2026年下半年，全球NOR闪存市场迎来近十年最重要的供需结构转变。受制程微缩、良率爬坡及客户验证周期长等因素影响，新增产能难以快速释放，导致高容量产品供应紧张。结果将是高容量NOR闪存价格可能翻倍，这一变化将加剧存储行业供需失衡，推高相关存储芯片成本。

背景

全球NOR闪存市场正面临近十年来最重大的供需结构变化。据DoNews报道，2026年下半年高容量NOR闪存产品供应将高度紧张，价格可能翻倍。TrendForce预测指出，NOR闪存增产有限，高容量产品价格在2026年下半年恐翻倍。这一趋势的背景是，继DRAM和NAND闪存短缺之后，NOR闪存正成为AI时代内存短缺的新焦点，人工智能（AI）正是NOR闪存供应紧张的关键推手。AI服务器等应用对NOR闪存的需求持续攀升，而NOR闪存凭借其独特的技术特性，在汽车电子、航天通信等高可靠性场景中不可或缺。与此同时，NAND Flash虽占据闪存市场95%以上份额，但NOR闪存在特定领域具有不可替代性。当前，DDR5、HBM等芯片已全面暴涨，仅剩DDR3、SLC及NOR三种还在价格洼地，补涨压力显著。

技术分析

NOR闪存供需结构剧变的核心原因在于供给端的多重约束。首先，制程微缩困难：NOR闪存向更先进节点演进面临物理极限，浮栅型NOR Flash在50nm以下进一步微缩的难度极大，武汉新芯虽已于2020年量产50nm浮栅型NOR Flash并达到国际领先存储密度，但继续微缩的边际成本急剧上升。其次，良率提升缓慢：高容量NOR闪存产品的良率爬坡周期长，新增产能无法迅速投入市场。第三，客户验证周期较长：NOR闪存广泛应用于汽车电子、工业控制、航天通信等高可靠性领域，客户对新产品导入的验证周期通常长达数月甚至数年，进一步延缓了新增产能的有效供给。从需求端看，AI推理模型日益向边缘端下沉，具备大容量NOR Flash的需求正在被重新定义；同时，AI服务器、汽车电子、航天通信等产业对NOR闪存的需求持续增长。国产新型超级闪存已突破NOR Flash容量极限，中天弘宇第二代产品的推出填补了市场空白，但整体供给弹性仍然有限。

市场影响

NOR闪存供需结构剧变将对全球存储市场产生深远影响。价格方面，TrendForce预测高容量NOR闪存产品价格在2026年下半年恐翻倍，这将是近十年来最重大的价格波动。细分市场方面，韩国NOR Flash市场规模预计将从1.4286亿美元增长至2035年，2025-2035年CAGR为4.67%，但短期价格翻倍将显著改变市场增速节奏。产业链方面，NOR闪存价格暴涨将推高汽车电子、工业控制、AI边缘设备、航天通信等下游领域的物料成本，部分终端产品可能面临涨价压力。资本市场方面，国内NOR闪存龙头武汉新芯实控人变更，长存控股出让武汉新芯39%股权，武汉光谷半导体产业投资有限公司收购该股权，这一资产梳理被市场解读为长江存储为冲刺整体上市而进行的业务边界切割，NOR闪存资产的价值重估正在发生。此外，DDR5、HBM等芯片已全面暴涨，仅剩DDR3、SLC及NOR三种还在洼地，NOR闪存的补涨行情可能吸引更多资本关注。

📋 一段话总结

2026年9月14日，美股盘前交易时段，光通信与存储芯片板块遭遇集体抛售，康宁、迈威尔科技、SK海力士、闪迪、美光科技、西部数据等个股普遍下跌4%至6%以上。起因是市场情绪转弱与AI利空消息冲击，经过为盘前资金集中撤离相关板块，结果导致光通信与存储芯片股价大幅承压。招商证券认为极致缩量后市场有望修复，建议关注加息落地后的科技成长与AI算力链机会。该事件短期内加剧了存储芯片板块的抛压，但机构观点认为缩量修复窗口临近，对存储行业中长期基本面影响有限。

背景

2026年9月14日美股盘前，光通信与存储芯片板块出现集体大幅下挫。存储芯片方面，SK海力士跌超6%，闪迪跌超5%，美光科技跌近5%，西部数据跌超4%；光通信方面，康宁跌超6%，迈威尔科技、Lumentum、Coherent跌超5%，Credo、Ciena跌近5%。同期亚太市场亦受波及，韩国综合指数下跌3.26%，铠侠跌6.37%，SK海力士跌6.35%，三星电子跌4.05%。从二次定向检索证据看，康宁的下跌存在公司层面的特殊催化：公司于上周五提交文件，宣布与高盛签署股权分销协议，拟通过'按市价发行'计划出售普通股，募资规模至多20亿美元，引发投资者对股东权益稀释的担忧，盘前一度跌超8%。此外，康宁此前因与Verizon签署价值数十亿美元、2032年前交付超8000万英里高密度光纤的多年期协议，以及与英伟达的认股权证安排（英伟达承诺出资高达32亿美元支持其产能扩张），股价今年迄今已上涨约91%，估值处于高位，对短期情绪变化和获利了结高度敏感。宏观层面，美国8月非农数据明显强于预期，美联储9月加息概率回升，国际油价重返100美元，市场已反映明年内美国加息三次以上的预期，纳斯达克100期货盘前跌1.61%，风险偏好整体承压。消息面上，Anthropic CEO呼吁行业放缓AI模型发展并引入第三方评估机构，OpenAI与xAI方面均表示认同，对AI产业链情绪形成一定扰动。

技术分析

从板块联动看，本轮下跌呈现光通信与存储芯片同步、美股与亚太市场共振的特征，属于典型的板块性系统性回调而非单一公司基本面恶化。康宁技术面显示，MACD(12,26,9)数值4.916处于中性状态，RSI数值54.918处于中性状态，Williams%R数值25.523处于买入状态，短期动量指标尚未进入超卖区间，但舆情指数处于极度看空状态，反映市场情绪与价格动能之间存在背离。康宁股价目前仍远低于6月270美元以上的峰值，二季度业绩公布后已出现大幅回落，叠加此次增发带来的潜在稀释，技术面处于高位回调后的震荡消化阶段。存储芯片方面，SK海力士、美光、西部数据等同步下挫，韩国综合指数单日跌3.26%，显示亚太存储产业链承压更为集中。招商证券指出，当前市场成交已进入过去一年极低区间，历史经验显示极致缩量后一周通常出现普遍修复，一个月后重新回归基本面与产业趋势定价，建议关注加息落地后的修复窗口。高盛亦指出，标普500预期市盈率已从年初22倍降至19倍，但指数仍处于距纪录高点2%以内的水平，过去几十年七次加息周期前三个月标普500平均下跌2%，但首次加息后12个月内上涨9%，为中期修复提供历史参照。

市场影响

本次板块集体杀跌对市场的影响可从三个层面理解。第一，短期情绪层面，光通信与存储芯片作为AI算力链的核心环节，其同步下挫反映市场对加息预期升温、AI模型发展节奏放缓信号以及高估值板块获利了结的集中释放。康宁的增发计划进一步放大了光通信板块的抛压，因为'按市价发行'不设固定价格与股数，公司可根据市场状况决定出售时机与规模，这种不确定性在弱市环境中容易被放大解读。第二，产业链层面，康宁与Verizon的协议交付预计2027年才开始，对当前季度盈利影响甚微，市场开始权衡其财务兑现的时间线；同时管理层承认传统消费电子和汽车板块持续疲软，企业数据通信和运营商市场则保持强劲，基本面分化加剧了股价对短期情绪的敏感度。第三，配置层面，招商证券建议围绕有业绩支撑的科技成长、AI算力链、CPO产业链及资源品涨价方向布局，重点把握加息落地后的修复窗口。高盛认为市场已充分反映加息预期，企业盈利和资产负债表均表现强劲，中期不宜过度悲观。整体而言，本次调整更接近估值与情绪的阶段性出清，而非AI算力与存储产业趋势的逆转，但短期波动率上升、板块内部分化加剧的格局或将延续。

背景

2026年9月14日美股盘前，存储芯片与光通信概念股集体重挫，直接导火索是Anthropic CEO达里奥·阿莫代伊公开呼吁全行业放缓前沿AI模型研发，并引入第三方评估机构等安全措施。OpenAI CEO萨姆·奥尔特曼随即表示采纳相关建议，xAI的埃隆·马斯克亦表态支持。三大AI领军人物罕见形成共识，市场迅速将其解读为AI算力需求可能放缓的信号，引发对光通信和存储芯片产业链的集中抛售。截至发稿，道琼斯期货跌0.13%至0.23%，纳斯达克100期货跌1.61%至1.75%，标普500期货跌0.68%至0.72%。个股方面，康宁跌超6%至7%，迈威尔科技跌超7%，SK海力士跌超6%，闪迪、美光科技、超威半导体等跌超5%，应用光电、Lumentum、Coherent跌超6%，Credo、Ciena跌近5%。亚太市场同步承压，日经225指数跌0.81%，韩国综合指数跌3.26%，铠侠跌6.37%，SK海力士跌6.35%，三星电子跌4.05%。值得注意的是，康宁的下跌还叠加了自身增发股票的独立利空——公司宣布通过“按市价发行”计划出售普通股，可能筹集高达20亿美元，引发股东权益稀释担忧。此前康宁股价今年迄今已上涨约91%，主要受AI基础设施关键卡位的乐观情绪推动，包括与Verizon达成数十亿美元多年期光纤供应协议、英伟达通过认股权证承诺出资高达32亿美元支持产能扩张等。

市场影响

背景

📋 一段话总结

2026年9月，德国 heise.de 报道，Ray-Ban Meta 智能眼镜因防偷拍机制可被简单遮挡绕过，录制无法被指示灯有效阻止，被指不符合欧盟隐私设计原则并可能违反 GDPR。监管机构指出，用户在公共场所拍摄他人或发布录像将失去家庭豁免，成为责任数据控制者；若默认允许 Meta 用交互数据训练 AI，还可能依第26条共同担责。该事件强化数据合规与数据主权要求，将推动企业级存储与云服务加强本地化留存、访问审计和隐私保护能力。

背景

2025年，汉堡数据保护专员Thomas Fuchs对Ray-Ban Meta AI智能眼镜展开专项调查，结论明确：在Meta未改进产品设计和默认设置的前提下，智能眼镜在公共场所的日常使用几乎不存在合法基础。此前，德国联邦网络局因缺乏管辖权未能采取行动，政界则出现了禁止智能眼镜的呼声。荷兰消费者协会也在推动禁令。与此同时，Meta智能眼镜已成为市场领导者，累计销量超过700万副，并计划最早于2025年推出名为“Name Tag”的面部识别功能。美国方面，德克萨斯州总检察长Ken Paxton于2025年5月对Ray-Ban Meta展开调查，纽约警察局反恐部门也警告该产品存在“安全和反间谍”威胁。这一事件的核心在于：智能眼镜的隐私设计缺陷与GDPR合规要求之间的根本冲突，以及用户作为数据控制者可能承担的个人法律责任。

技术分析

汉堡数据保护机构的调查从技术和法律两个层面展开。技术层面，调查人员拆解了2023年发布的第一代Ray-Ban Meta Wayfarer，拦截了Meta AI伴侣应用的网络流量，并尝试通过Meta账户中心提交数据访问请求。硬件配置上，该眼镜集成了1200万像素广角摄像头、五个麦克风、两个扬声器、32GB闪存、Wi-Fi和蓝牙模块，以及高通AI处理器和BIWIN存储芯片。调查人员无法直接从存储芯片读取数据，因为该芯片缺乏可访问的接触点，标准工具无法读取。更关键的是，防偷拍机制存在严重设计缺陷：录制启动后，即使用锡箔或盖子遮住LED指示灯，视频录制仍会继续。这意味着旁观者无法通过视觉信号判断自己是否正在被记录，直接违反了欧盟隐私设计原则。GDPR第26条关于共同控制者的规定在此场景下尤为关键：若用户默认允许Meta使用交互数据训练AI，用户可能与Meta构成共同数据控制者，承担连带责任。此外，Meta为第三方（即被拍摄的旁观者）提供的反对机制不具备追溯力，且使用起来比佩戴者自身的退出机制繁琐得多，进一步加剧了合规风险。

市场影响

该事件对智能眼镜市场的影响是多维度的。首先，欧洲市场的合规压力将显著上升。汉堡监管机构的结论实质上宣告了当前形态的Ray-Ban Meta眼镜在公共场所的日常使用缺乏合法基础，这可能迫使Meta调整产品设计，例如强化LED指示灯的防篡改能力、增加旁观者同意机制，或限制默认数据用于AI训练。其次，用户法律责任风险可能抑制消费需求。GDPR第26条下的共同控制者责任意味着普通用户可能因日常拍摄行为面临法律追责，这将削弱产品的吸引力。第三，监管碎片化加剧市场不确定性。美国德州和纽约的执法机构已表达关切，荷兰消费者协会推动禁令，但各国监管力度不一，Meta可能面临不同市场的差异化合规要求。第四，面部识别功能“Name Tag”的推出计划可能因隐私反弹而推迟或调整。Meta内部备忘录显示其计划利用政治环境窗口期发布该功能，但汉堡调查结果可能改变这一算计。总体而言，该事件将加速智能眼镜行业从“先发布后合规”向“隐私设计优先”的范式转变。
